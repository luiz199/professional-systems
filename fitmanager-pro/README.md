---

## 📋 Funcionalidades

| Módulo | Descrição |
|--------|-----------|
| 📊 **Dashboard** | Métricas de alunos ativos, inadimplentes, receita mensal e gráficos |
| 👥 **Alunos** | Cadastro completo com CRUD, busca, status (ativo/inadimplente) |
| 💰 **Financeiro** | Controle de mensalidades com relatório de inadimplência |
| 📋 **Fichas de Treino** | Criação de treinos A/B/C com exercícios, séries e repetições |
| 🚪 **Catraca Virtual** | Acesso por CPF com animação de liberação/bloqueio |
| 🔔 **Alertas** | Painel de notificações de vencimentos e alunos inadimplentes |
| 🌙 **Tema Dark/Light** | Alternância com animação suave |

## 🚀 Primeiro Acesso

1. Abra `index.html` no navegador
2. Na **primeira execução**, configure as credenciais de **Administrador**
3. O sistema já vem com **5 alunos fictícios** para demonstração
4. Faça login e explore todas as funcionalidades

> ⚠️ **Não há senhas padrão.** O primeiro acesso cria automaticamente o administrador.

## 💾 Armazenamento

Dados salvos em **LocalStorage**. Nenhum servidor necessário.

## 🎨 Design

- **Glassmorphism** com cards translúcidos e backdrop blur
- **Gradientes** vibrantes no sidebar e header
- Interface responsiva e animada (fade-in, slide-up, scale-in)

## 🛠️ Tecnologias

- HTML5
- Tailwind CSS (CDN)
- Alpine.js 3.x (CDN)
- Lucide Icons
- LocalStorage API
