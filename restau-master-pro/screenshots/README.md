# 📸 Screenshots — RESTAU MASTER PRO

> Capturas de tela do sistema. Para gerar os placeholders, execute o script `../generate-screenshots.ps1`.

| Imagem | Descrição |
|--------|-----------|
| `login.png` | Tela de login / configuração inicial |
| `dashboard.png` | Dashboard com métricas e gráficos |
| `mesas.png` | Mapa visual de mesas |
| `cardapio.png` | Cardápio com fotos e categorias |
| `pedidos.png` | Sistema de comanda / pedidos |
| `admin.png` | Painel administrativo |
| `dark-mode.png` | Visualização do tema escuro |
| `light-mode.png` | Visualização do tema claro |

## 🎯 Para capturas reais

1. Abra `../index.html` no navegador
2. Faça login como administrador
3. Navegue até cada tela
4. Capture com ferramenta de screenshot (Win+Shift+S, Snagit, etc.)
5. Substitua os placeholders pelos arquivos PNG reais
