## 📋 Funcionalidades

| Módulo | Descrição |
|--------|-----------|
| 📊 **Dashboard** | Visão geral do faturamento, pedidos ativos, ticket médio e gráficos |
| 🗺️ **Mapa de Mesas** | Layout visual interativo com status de cada mesa (livre/ocupada/fechando) |
| 📝 **Pedidos Digitais** | Sistema completo de comandas com adição/remoção de itens |
| 📸 **Cardápio com Fotos** | Cadastro de produtos com imagens, categorias e preços |
| 💳 **Pagamentos** | Suporte a Dinheiro, Cartão, PIX e Débito com cálculo de troco |
| 📜 **Histórico** | Registro completo de pedidos finalizados com filtros por data |
| 👥 **Admin - Usuários** | Gerenciamento de funcionários com permissões por nível |
| ⚙️ **Admin - Configurações** | Nome do estabelecimento, impostos, formas de pagamento ativas |
| 🔧 **Admin - Manutenção** | Backup/restore de dados, reset do sistema |
| 🌙 **Tema Dark/Light** | Alternância suave com CSS Variables |

## 🚀 Primeiro Acesso

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Na **primeira execução**, o sistema exibirá a tela de configuração inicial
3. Defina suas credenciais de **Administrador Master**
4. Pronto! Faça login e comece a usar

> ⚠️ **Não há senhas padrão.** O primeiro acesso cria automaticamente o administrador.

## 💾 Armazenamento

Todos os dados são salvos no **LocalStorage** do navegador. Nenhum servidor ou banco de dados externo é necessário. Faça backups regulares pelo painel de manutenção.

## 🎨 Personalização

O sistema utiliza **CSS Variables** para temas. O tema padrão é escuro (`dark`), com alternância para o modo claro via botão no sidebar.

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 Puro (Flexbox, Grid, Animations, Variables)
- JavaScript Vanilla (ES6+)
- localStorage API
- Chart.js (gráficos do dashboard)
