# 📸 Screenshots — DataMind AI

> Capturas de tela do sistema. Para gerar os placeholders, execute o script `../generate-screenshots.ps1`.

| Imagem | Descrição |
|--------|-----------|
| `hero.png` | Hero page com animação e partículas |
| `servicos.png` | Cards de serviços (IA, Automação, etc.) |
| `planos.png` | Tabela de preços (3 planos) |
| `chat.png` | Chat IA em funcionamento |
| `clima.png` | Previsão do tempo (5 dias) |
| `admin.png` | Painel administrativo |
| `mobile.png` | Versão responsiva mobile |

## 🎯 Para capturas reais

1. Abra `../index.html` no navegador
2. Faça login (qualquer email/senha)
3. Navegue entre as seções
4. Capture com ferramenta de screenshot
5. Substitua os placeholders pelos arquivos PNG reais
